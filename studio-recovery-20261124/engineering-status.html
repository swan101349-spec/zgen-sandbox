Sequence for the Ferrari

Stage 1: Lucy 4.0 verification. Validate GitHub protection, mandatory independent exact-head checks, the no-bypass policy, watchdog and negative merge-denial proof.

Stage 2: Lucy 5.0 engineering. Extend the one existing Lucy/S0 26-job controller with dependable component testing, independent C3 receipts, guarded repairs, useful failure reports and safe restart recovery. Do not create a second queue.

Stage 3: Tier 1 assembly. Integrate passing tools into the existing authentic painter with isolated end-to-end tests. Preserve brush physics, originals and artwork. Verify Save/Open, wet state, Undo/Redo, tools, actual phone/tablet behavior and safe delivery.

Stage 4: Artist beta feedback. Once the platform is genuinely operable, conduct OPPO and Galaxy Tab S9 / S Pen sessions and devote remaining work to refinements and additions.

Lucy as a continually operating autonomous engineering assistant is a future runtime target, not something this documentation page installs or proves today.

Known owner issues: 2B pencil selection, Fill availability, imported-reference survival, stable shortcut, Fit/sliders discoverability, gallery integration and incomplete Tier 1 tools.
